# Digital Marketing Capstone Project

## Project Overview
This project documents the practical assignments completed during my two-month remote Digital Marketing Internship at GrowAI EdTech. It covers digital marketing strategy, content creation, SEO, advertising, email marketing, and analytics.

## Modules and Activities

### Module 1: Marketing Strategy
- Studied the 7Ps of Marketing.
- Conducted a SWOT Analysis.

### Module 2: Promotional Poster Design
- Recreated a promotional poster using Canva AI.

### Module 3: Social Media Content Analysis
- Analyzed Instagram page content.
- Suggested improvements to content and engagement strategies.

### Module 4: Meta Ads Campaign
- Practiced setting up an e-commerce sales campaign using Meta Ads Manager.

### Module 5: SEO and Blogger Website
- Created and optimized a Blogger website.
- Practiced off-page SEO techniques, including profile creation, social bookmarking, image submission, and PDF submission.

### Module 6: Google Ads and Business Profile
- Practiced Google Ads lead-generation campaign setup.
- Worked on Google Business Profile setup.

### Module 7: Email Marketing
- Created email newsletter campaigns using Brevo.
  
### Module 8: Google Analytics 4
- Practiced GA4 integration and website performance tracking.
